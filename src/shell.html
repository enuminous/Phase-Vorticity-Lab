MODEL & PROVENANCE

What this laboratory establishes

This is a kinematic test bed for a registered family of two-dimensional vortices. It checks global U(1) symmetry, planar rotation covariance, the phase-current identity, the regularized curl, and rotating-frame normalization before a numerical Biot–Savart evaluation.

The frozen model

Set a = ℏ/m = 1 in dimensionless units; ψ = ρ exp(iθ), θ = Σ nᵢ arg(x−xᵢ), and ρ = Π[rᵢ/√(rᵢ²+ε²)]|nᵢ|. The regularized fluid velocity is uᵢ = a nᵢ (−yᵢ,xᵢ)/(rᵢ²+ε²), with ωᵢ = 2a nᵢ ε²/(rᵢ²+ε²)². This regularization is a declared modeling choice, not a theorem that replaces the singular phase velocity.

The boundary contract

The kernel is the whole-plane 2D fluid kernel K(r) = (−rᵧ,rₓ)/(2π|r|²). Vorticity is sampled in a finite square of half-width 4, rotated with the configuration. Omitted tails and midpoint quadrature create error. This is not a no-through-flow box, a 3D magnetic field, or a cosmological solution. There is no evolving Schrödinger or Euler solver.
